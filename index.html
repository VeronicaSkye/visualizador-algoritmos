Fundamentos de Algoritmos & Análise Assintótica

🎯 O que é a Notação Big-O?

Na Engenharia de Software, a notação Big-O mede como o tempo de execução ou o consumo de memória de um algoritmo cresce à medida que o tamanho dos dados de entrada ($n$) aumenta. Ela avalia a eficiência e escalabilidade de uma solução.

⚡ Hierarquia das Complexidades Mais Comuns

Notação Nome Exemplo Típico Desempenho
O(1) Constante Acessar elemento por índice em um array Excelente
O(log n) Logarítmica Busca Binária Muito Bom
O(n) Linear Busca Simples (varredura de ponta a ponta) Aceitável
O(n log n) Quasilinear Merge Sort, Quick Sort (médio), Heap Sort Padrão Ouro p/ Ordenação
O(n²) Quadrática Bubble Sort, Selection Sort (dois loops aninhados) Lento para grandes $n$

💡 Por que esse conhecimento é valioso para entrevistas técnicas?

Grandes empresas de tecnologia avaliam se um engenheiro consegue prever gargalos de performance antes de escrever o código. Saber quando escolher entre um algoritmo estável (como Merge Sort) e um algoritmo in-place de alta velocidade (como Quick Sort) é um diferencial decisivo!
